Guia Rápido para a Equipe

Regra de Ouro: Com Docente × Sem Docente (SD)

📅 Agendas WEB Presencial são semestrais. As demais agendas são trimestrais (arquivo termina com _ANO_TRIMESTRE, ex.: COMUM_2026_4). Os links WEB são usados somente no 1º trimestre (início em janeiro, arquivo termina _ANO_1, ex.: AGENDAS_2026_1/WEB_2026_1.html) e no 3º trimestre (início em julho, arquivo termina _ANO_2, ex.: AGENDAS_2026_3/WEB_2026_2.html). No 2º e no 4º trimestre não existe agenda WEB. Se aparecer uma disciplina WEB nesses trimestres, fale com o responsável. A conferência da planilha marca isso como erro.
As agendas WEB TOTVS (ex.: WEB_SD_TOTVS_2026_4) são trimestrais.

SD significa SEM DOCENTE. Todo cartão mostra uma etiqueta 👨‍🏫 Com Docente ou ⚡ Sem Docente (SD). Na dúvida, não copie: pergunte ao responsável.

1

Pegar o link certo para uma disciplina

  1. Na aba 1. Consultar Agendas, confira se o período no topo é o do trimestre que você está lançando (o período atual já vem selecionado).
  2. Use o Assistente: grupo + características (pode marcar mais de uma, ex.: PI + SD).
  3. Leia "Quando usar esta agenda" e clique em Visualizar para conferir as datas.
  4. Clique em Copiar Link. Cartão amarelo = datas ainda não atualizadas, a cópia fica bloqueada.
2

Conferir a planilha inteira antes de lançar

  1. Abra a aba 2. Conferir Planilha e escolha o trimestre.
  2. No Excel, copie as colunas da disciplina e a coluna do link e cole no quadro.
  3. Clique em Conferir. Verde = certo; amarelo = revisar; vermelho = errado.
  4. Clique em Copiar coluna "Link correto" e cole por cima da coluna de links da planilha (mesma ordem das linhas).
3

(Admin) Virada de trimestre

  1. Em 3. Gerenciar → Virada de Trimestre: digite o novo período (ex.: 2027-1) e copie do anterior. As agendas WEB só são criadas no 1º e no 3º trimestre (final _ANO_1/_ANO_2); no 2º e no 4º elas não são copiadas. Alternativa: cole a coluna de links da nova aba da planilha em "Planilha de links ⇄ Painel".
  2. Revise a lista de links que não seguiram o padrão.
  3. Suba os novos HTMLs das agendas no GitHub como sempre.
  4. Rode o Diagnóstico → Testar se os links abrem. Libere (verde) cada agenda conforme atualizar as datas.
  5. Marque o novo período com ⭐ (período atual) e Publique.
4

(Admin) Publicar alterações

  1. Tudo que você muda fica em rascunho (faixa amarela no topo). A equipe ainda não vê.
  2. Clique em Publicar (baixar agendas.json).
  3. No GitHub, entre na pasta deste painel → Add file → Upload files → arraste o agendas.json → Commit.
  4. Em 1 a 2 minutos a equipe vê os dados novos (basta recarregar). O rascunho some sozinho quando a versão publicada chega.
  5. Se errar algo, o histórico do GitHub guarda todas as versões do agendas.json.
