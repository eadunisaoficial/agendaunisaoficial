Disciplinas Específicas e Tipos de Agenda

Algumas disciplinas não seguem a agenda que o nome sugere (ex.: um "Projeto Integrador" que é avaliado como regular). Na dúvida, procure a disciplina aqui antes de escolher a agenda.

Como ler: ATIV = avaliação por atividade única (uma entrega) AVC + AVI + AVG = avaliações regulares (as três provas do calendário) Tipo de agenda = o número (Id) que define as datas; clique nele para ver os detalhes

Editar o conteúdo das agendas (datas, textos e botões)

Tudo o que você altera aqui vai para o agendas.json. As agendas leem as datas desse arquivo ao abrir; não é preciso editar arquivo por arquivo. O layout das agendas continua o mesmo.

Com o GitHub conectado (recomendado)

  1. Escolha o período e clique em Carregar agendas do GitHub (não precisa de token; só na primeira vez de cada agenda).
  2. Edite as agendas (uma a uma ou em lote).
  3. Clique em Salvar no GitHub: revise as alterações → cole o token → confira a lista de arquivos → marque "Conferi" → Gravar.
  4. Em 1 a 2 minutos as agendas mostram as novas datas. Na primeira gravação, cada agenda recebe também a linha que a faz ler o agendas.json.

Sem conexão com o GitHub (alternativa manual)

  1. Clique em Importar do computador e selecione os arquivos .html da pasta (ex.: AGENDAS_2026_4).
  2. O painel lê as datas, textos, botões e itens ocultos de cada agenda.
  3. Clique em Baixar arquivos do período (.zip). O ZIP traz os mesmos HTMLs com uma linha a mais e o arquivo agenda-dinamica.js.
  4. Descompacte e suba no GitHub: agenda-dinamica.js na raiz (junto do agendas.json) e os HTMLs na pasta do período, substituindo os atuais.
  5. Publique o agendas.json. Pronto: daqui em diante, só o agendas.json muda.

Dia a dia

  • Uma agenda: clique nela na lista e edite. A prévia ao lado mostra como o aluno vai ver.
  • Várias agendas: marque as caixinhas e use Alterar em lote (trocar uma data em todas, mudar a data de "Divulgação de notas", ocultar um item, deslocar o calendário...).
  • Ocultar/mostrar: o olho em cada item ou botão. Item oculto não aparece para o aluno, mas fica guardado.
  • Salve publicando o agendas.json no GitHub, como você já faz.
  • Baixar arquivos atualizados: no ícone de cada agenda (um .html), em Baixar marcadas (as que você marcar) ou em Baixar arquivos do período. Os arquivos saem com as datas atuais gravadas, servindo de cópia de segurança caso o JSON falhe.
  • Segurança: se o agendas.json não carregar, a agenda mostra o conteúdo gravado no próprio arquivo HTML.
Guia Rápido para a Equipe

Regra de Ouro: Com Docente × Sem Docente (SD)

📅 Agendas WEB Presencial são semestrais. As demais agendas são trimestrais (arquivo termina com _ANO_TRIMESTRE, ex.: COMUM_2026_4). Os links WEB são usados somente no 1º trimestre (início em janeiro, arquivo termina _ANO_1, ex.: AGENDAS_2026_1/WEB_2026_1.html) e no 3º trimestre (início em julho, arquivo termina _ANO_2, ex.: AGENDAS_2026_3/WEB_2026_2.html). No 2º e no 4º trimestre não existe agenda WEB. Se aparecer uma disciplina WEB nesses trimestres, fale com o responsável. A conferência da planilha marca isso como erro.
As agendas WEB TOTVS (ex.: WEB_SD_TOTVS_2026_4) são trimestrais.

SD significa SEM DOCENTE. Todo cartão mostra uma etiqueta 👨‍🏫 Com Docente ou ⚡ Sem Docente (SD). Na dúvida, não copie: pergunte ao responsável.

1

Pegar o link certo para uma disciplina

  1. Na aba 1. Consultar Agendas, confira se o período no topo é o do trimestre que você está lançando (o período atual já vem selecionado).
  2. Use o Assistente: grupo + características (pode marcar mais de uma, ex.: PI + SD).
  3. Leia "Quando usar esta agenda" e clique em Visualizar para conferir as datas.
  4. Clique em Copiar Link. Cartão amarelo = datas ainda não atualizadas, a cópia fica bloqueada.
2

Conferir a planilha inteira antes de lançar

  1. Abra a aba 3. Conferir Planilha e escolha o trimestre.
  2. No Excel, copie as colunas da disciplina e a coluna do link e cole no quadro.
  3. Clique em Conferir. Verde = certo; amarelo = revisar; vermelho = errado.
  4. Clique em Copiar coluna "Link correto" e cole por cima da coluna de links da planilha (mesma ordem das linhas).

Ficou em dúvida sobre uma disciplina?

  1. Abra a aba 2. Disciplinas Específicas e digite parte do nome da disciplina.
  2. Veja o método de avaliação (ATIV = atividade única; AVC + AVI + AVG = regular) e o tipo de agenda.
  3. Clique em Ver agenda no painel para ir direto ao link certo do trimestre. Na dúvida entre Com Docente e SD, confira a disciplina.
  4. Se o cartão mostrar ⚠ Confirmar com o responsável, não escolha sozinho: pergunte antes.

Dica: na aba 1, ao buscar o nome de uma disciplina específica, aparece um aviso roxo com o tipo de agenda dela.

3

(Admin) Virada de trimestre

  1. Em 4. Gerenciar → Virada de Trimestre: digite o novo período (ex.: 2027-1) e copie do anterior. As agendas WEB só são criadas no 1º e no 3º trimestre (final _ANO_1/_ANO_2); no 2º e no 4º elas não são copiadas. Alternativa: cole a coluna de links da nova aba da planilha em "Planilha de links ⇄ Painel".
  2. Revise a lista de links que não seguiram o padrão.
  3. Suba os novos HTMLs das agendas no GitHub como sempre.
  4. Rode o Diagnóstico → Testar se os links abrem. Libere (verde) cada agenda conforme atualizar as datas.
  5. Marque o novo período com ⭐ (período atual) e Publique.
5

(Admin) Alterar datas das agendas

  1. Em 5. Editar Conteúdo, escolha o período. Na primeira vez, importe os HTMLs e suba o ZIP gerado (veja "Como funciona / 1ª vez").
  2. Clique numa agenda para editar datas, textos, botões e itens ocultos, com prévia ao lado.
  3. Para várias agendas: marque-as e use Alterar em lote.
  4. Publique o agendas.json. As agendas passam a mostrar as novas datas sozinhas.
4

(Admin) Publicar alterações

  1. Tudo que você muda fica em rascunho (faixa amarela no topo). A equipe ainda não vê.
  2. Clique em Salvar no GitHub, revise, cole o token e confirme. (Alternativa manual: Baixar agendas.json e subir pelo site do GitHub.)
  3. Em 1 a 2 minutos a equipe vê os dados novos (basta recarregar). O rascunho some sozinho quando a versão publicada chega.
  4. Se errar algo, o histórico do GitHub guarda todas as versões do agendas.json.
